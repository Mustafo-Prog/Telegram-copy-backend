# Сервер мессенджера

Запуск: `npm install`, затем `npm run dev` или `npm start`. Переменные окружения перечислены в `.env.example`.

Проверки: `npm test`. HTTP- и Socket.IO-тесты используют базу в памяти и временные локальные серверы.

## Избранное

- `POST /api/conversations/saved` возвращает `{ conversation }`: личное «Избранное» текущего пользователя. Повторный запрос открывает тот же чат.
- `POST /api/conversations/saved/messages/:messageId` возвращает `201 { conversation, message }` и сохраняет отдельную копию доступного сообщения, включая файл или голосовую запись. Удаление оригинала не удаляет сохранённую копию.
- Для заметок, загрузки истории, поиска, редактирования и удаления используются обычные `/api/conversations/:id/...` маршруты. `kind` такого чата — `saved`, `peer` — `null`. Чат и его файлы доступны только владельцу.
- `message.savedFrom` содержит имя исходного автора и время оригинала. Цитата из другого чата не переносится.

Для этой функции новые переменные окружения не нужны.

## Синхронизация

Закрепление возвращает только `{ conversation: { id, pinnedAt } }`. Клиент должен объединять эти поля с сохранённым чатом. Событие `chat:changed` с `reason: pin` содержит `conversationId` и `pinnedAt`.

Полные DTO диалогов содержат `lastMessageId`. Отправка текстом или `multipart/form-data` принимает необязательный `clientMessageId` (строка длиной 1–80 символов), который возвращается в сообщении и событии Socket.IO для сопоставления с локальным индикатором отправки. Это идентификатор интерфейса, а не гарантия повторной отправки без дублей.
